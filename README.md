# Сила чисел

Одностраничный сайт бухгалтерских услуг. Проект состоит из обычных HTML, CSS и JavaScript файлов и не требует сборки.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер в этой папке.

## Публикация

Сайт публикуется через GitHub Pages. Workflow в `.github/workflows/pages.yml` автоматически выкладывает содержимое корня репозитория при каждом push в ветку `main`.
